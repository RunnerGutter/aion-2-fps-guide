## 🔍 Why Does AION 2 Stutter?

The problem is usually a combination of three things:

1. **Shader Compilation Stutter**
   Every time the game loads a new effect, spell, or character model, it compiles shaders on the fly. This causes brief but severe stutters, especially in busy areas.

2. **Background Process Interference**
   Windows services, browser tabs, and background apps compete with the game for CPU resources. When the game needs that CPU time to render a raid, it's not there.

3. **Improper GPU Scheduling**
   If Windows isn't prioritizing the game properly, your GPU might be waiting for instructions while the CPU handles background tasks. This causes frame-time spikes and input lag.
